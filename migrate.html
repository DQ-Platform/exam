Supabase → Firebase köçürmə

1) Firebase bağlantısı
dq-firebase.js-də config doldurulmalıdır.
2) Supabase-dən çıxarılmış faylları seçin
Supabase → Table Editor → cədvəl → Export → CSV. Cədvəllər: allowed_students, exam_questions, exam_results, dq_v2_store. Fayl adı cədvəl adı ilə başlamalıdır (məs. exam_questions.csv). JSON da (massiv) olar.
Hazırdır.
